# Каталог тканей в Telegram

Бот показывает каталог тканей и принимает заявки на бронь во время прямого эфира. Оплаты и 1С нет: менеджер подтверждает бронь сам.

## Клиент

- **LIVE СЕЙЧАС** — ссылка на трансляцию, если эфир включён.
- **КАТАЛОГ** — карточки с фото, характеристиками, ценой и остатком. Кнопка «Забронировать».
- **МОЙ МЕНЕДЖЕР** — контакт, который задаётся в админке.
- **ПОМОЩЬ** — короткая инструкция.

Во время эфира в карточке показывается LIVE-цена. Заявка спрашивает имя, телефон, компанию и метраж, затем просит подтвердить. Клиент видит: «Заявка принята! Менеджер свяжется с вами.»

Остаток при брони не списывается.

## Админ

Команда `/admin` доступна аккаунтам из `ADMIN_USERNAMES` и `ADMIN_IDS`. В меню бота она появляется после первого `/start`.

- Добавить товар: фото, название, характеристики, обычная цена, LIVE-цена, остаток.
- Изменить цену, LIVE-цену, остаток, описание, фото. Товар можно скрыть или удалить.
- Включить LIVE и вставить ссылку на трансляцию. Выключение возвращает обычную цену.
- Заявки: кто, какая ткань, сколько метров, телефон. Если у клиента есть @username, есть кнопка «Написать». Иначе в тексте ссылка на профиль.

Новая заявка также приходит личным сообщением всем админам, которые уже нажимали `/start`.

## Запуск локально

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
```

В `.env` укажите токен от @BotFather. Затем:

```bash
.venv/bin/python -m bot
```

Проверки:

```bash
.venv/bin/pip install pytest
.venv/bin/pytest
```

## Сервер

Бот работает через long polling, домен не нужен. На сервере нужны файлы проекта, `.env` и systemd:

```bash
# .env
BOT_TOKEN=...
ADMIN_USERNAMES=Grigori_G_979
DATABASE_PATH=/opt/grigory-bot/data/bot.db
```

```bash
bash deploy/install.sh
```

Юнит: `grigory-bot`. Логи: `journalctl -u grigory-bot -f`.

## Как устроена цена

У каждой ткани две цены: обычная и LIVE. Переключатель эфира общий. Пока LIVE выключен, клиент видит обычную цену. Пока включён — LIVE-цену и ссылку на трансляцию. Характеристики — свободный текст: состав, ширина, плотность, цвет.
